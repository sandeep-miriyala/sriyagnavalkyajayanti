## ✨ వెబ్‌సైట్‌లో ఉన్నవి

- **ఆహ్వానం** – తేదీ, సమయం, ప్రదేశం, జయంతికి ఇంకా ఎన్ని రోజులు ఉన్నాయో లెక్క
- **వాట్సాప్‌లో పంపండి** – ఆహ్వాన పత్రిక మరియు ప్రతి పుస్తకాన్ని PDF గా నేరుగా వాట్సాప్‌లో పంపవచ్చు
- **దారి చూపించు** – గూగుల్ మ్యాప్‌లో దేవాలయానికి దారి
- **క్యాలెండర్‌లో గుర్తు** – ఒక రోజు ముందు గుర్తు చేస్తుంది
- **చదివి వినిపించు** – ఆహ్వానం, ఉపదేశం తెలుగులో చదివి వినిపిస్తుంది
- **24×7 సహాయ మిత్ర** – జయంతి గురించి ఏ ప్రశ్న అయినా అడగండి; కొత్త సమాధానం పైన కనిపిస్తుంది; 🎤 మాట్లాడి కూడా అడగవచ్చు
- **మహర్షి ఉపదేశం** – 2026 ఆహ్వాన పత్రికలోని "ప్రపంచం తెలుసుకోవాల్సిన మహర్షి"
- **మహర్షి చరిత్ర**, స్తుతి శ్లోకాలు, భావం
- **మీ ప్రవర** – పేరు, గోత్రం ఎంచుకుంటే శుక్ల యజుర్వేద ప్రవర (వివరాలు ఎక్కడా సేవ్ చేయబడవు)
- **క్విజ్** – 5 ప్రశ్నలు, పూర్తి చేస్తే సర్టిఫికెట్
- **వర్చువల్ దీపం** – మహర్షికి దీపం వెలిగించండి

- **మరిన్ని సైట్లు** – [వాజసనేయీ సంధ్యావందనం](https://vajasaneyasandhya.vercel.app/) నేర్చుకోండి

## 👵 పెద్దవారికి సులభంగా

- అక్షరాలు పెద్దవి (22px నుండి 28px వరకు) – **− అ / + అ** బటన్లు
- **23 ఉచిత తెలుగు అక్షర శైలులు** (మండలి, రామభద్ర, ఎన్టీఆర్, గురజాడ, సిరివెన్నెల…) – ఎంచుకుంటే వెబ్‌సైట్ అంతా మారుతుంది
- **పగలు / రాత్రి రంగులు**
- అంతా తెలుగులోనే; ఫోన్ నంబర్లు ఎక్కడా లేవు
- పెద్ద బటన్లు, సులభమైన మెనూ, క్రింద త్వరిత బటన్ల పట్టీ
- **WCAG 2.2 AA** ప్రమాణాల ప్రకారం రంగులు మరియు అక్షరాలు
- ఫోన్‌లో **యాప్‌గా ఇన్‌స్టాల్** చేసుకోవచ్చు; ఇంటర్నెట్ లేకున్నా తెరుచుకుంటుంది

## 🎨 బాపిరాజు గారి చిత్రాలు జోడించడం

1. చిత్రాన్ని `paintings/` ఫోల్డర్‌లో `month-01.jpg` … `month-12.jpg` పేరుతో పెట్టండి (ఉదా: 5వ నెల → `paintings/month-05.jpg`).
2. `paintings.js` లో ఆ నెల `title` కు చిత్రం పేరు తెలుగులో రాయండి.
3. `service-worker.js` లో `CACHE_NAME` సంఖ్య పెంచి, `git push` చేయండి.

చిత్రం లేని నెలకు వెబ్‌సైట్‌లో "త్వరలో" అని కనిపిస్తుంది.

## 🌐 మరో సంబంధిత వెబ్‌సైట్ జోడించడం

`index.html` లో `id="related"` విభాగంలో ఉన్న `<li class="related-item">…</li>` ను కాపీ చేసి పేరు, వివరణ, లింక్ మార్చండి.

## 🛠️ కంప్యూటర్‌లో పరీక్షించడం (Local testing)

**Windows:** ఫోల్డర్‌లో ఉన్న `start-site.bat` ను డబుల్-క్లిక్ చేయండి. బ్రౌజర్‌లో http://localhost:8000 తెరుచుకుంటుంది.

లేదా టెర్మినల్‌లో:

```bash
python -m http.server 8000
```

> `index.html` ను నేరుగా డబుల్-క్లిక్ చేయవద్దు – యాప్ ఇన్‌స్టాల్, ఆఫ్‌లైన్ వంటివి పనిచేయవు.

## 🚀 ప్రచురణ (Deploy)

`main` బ్రాంచ్‌కు `git push` చేస్తే **Netlify** తనంతట అదే వెబ్‌సైట్‌ను అప్‌డేట్ చేస్తుంది.

వెబ్‌సైట్ మార్చిన ప్రతిసారీ `service-worker.js` లో `CACHE_NAME` సంఖ్య పెంచండి (ఉదా: `v5` → `v6`), అప్పుడు ఇన్‌స్టాల్ చేసుకున్న వారికి కూడా కొత్త పేజీ వస్తుంది.
